Usei o IP do meu celular para dar o ping, aí deu pra ver muito bem os pacotes Echo (ping) request enviados pelo cliente (meu PC)
e as respostas Echo (ping) reply devolvidas pelo host de destino ( meu celular ). Como exemplo na captura da imagem acima, o primeiro
pedido (21) obteve uma resposta com o tempo de ida e volta (RTT) de aproximadamente 12,5 ms, calculado a partir da diferença entre o 
tempo de resposta (linha 22) e o de envio (linha 21) da coluna time das respectivas linhas.
