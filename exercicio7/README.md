Analisando o trágefo DNS é possível ver o envio de pedidos "Standard query" para o servido DNS local (192.168.15.1) fazendo a consulta de registros tanto do tipo A (ipv4) 
quando do AAAA (ipv6) para domínios como os serviços da Mozilla. E na respostas o servidor devolve além dos endereços IP resolvidos, ele também demonstra o uso de registros CNAME
mapeando aliases para os seus nomes de domínio.
