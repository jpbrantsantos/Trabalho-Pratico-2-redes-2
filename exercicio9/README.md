A captura do tráfego de configuração dinâmica de rede ilustra as quatro fases do processo DORA. Inicialmente, observa-se o pacote de broadcast DHCP Discover (linha 19) 
enviado pelo cliente (0.0.0.0) em busca de servidores DHCP na rede. O router (192.168.15.1) responde com o pacote DHCP Offer (linha 20), oferecendo o IP 192.168.15.179. 
De seguida, o cliente confirma a aceitação do endereço através do pacote de broadcast DHCP Request (linha 21). 
O processo finalizou quando o servidor enviou o pacote DHCP ACK (linha 23), efetivando a concessão do endereço IP para a interface de rede do cliente.
